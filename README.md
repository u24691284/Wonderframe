# Wonderframe

IMY 220 Photo Sharing Website

## Theme 
WonderFrame is a modern photography and a photo-sharing platform where users can upload and share memorable moments through images.

## Project Description
Wonderframe is a photo-sharing website developed for IMY 220 project. Users can create profile, upload photos, interact with posts, browse local and global feeds and discover photogrpahy shared by the community.
